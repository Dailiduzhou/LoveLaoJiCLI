# one

只展示一个下一步，不做项目管理。

```sh
one add "检查令牌过期时间"
one
one done
cat TODO.md | one
one < TODO.md
```

## 持久化任务

所有目录共用一个本地列表，不按项目分组。`add` 接受 trim 后非空单行，
最多 2,000 个 Unicode 字符、无控制字符；最多 1,000 项未完成任务，允许重复。
添加不会选择任务或改变已有选中项。

直接运行 `one` 均匀随机选择一项，先持久化 `selected_task_id` 再只显示这一项。
之后无论 seed/cwd 如何变化都保持选中项。`done` 删除选中任务并清空 ID，
下次直接运行才重新选择。不保存完成历史；没有选中项的 `done` 友好成功，
不会代选或完成其他任务。空列表成功输出“没有待选事项。”
没有优先级、项目、截止时间、标签或分数。

状态位于 `${XDG_STATE_HOME:-$HOME/.local/state}/lovelaojicli/one/tasks.json`。
共享存储提供目录 0700、文件 0600、非阻塞 OS 锁（`one/tasks.lock`）、
原子替换及带密钥版本化 JSON 校验。无效/相对 XDG 回退绝对 HOME。
损坏、未知 schema、不安全权限、符号链接和锁争用均返回 1，不重置或覆盖任务。
读/选择/写在同一锁范围；并发调用遇到 1 可能需要重试。卸载保留状态。

任务是**本地明文**，不是加密内容。不要填写秘密；命令行参数也可能进入 shell
历史和进程列表。当前记录只保留未完成任务；删除不保证从磁盘或备份安全擦除。

## 临时输入

管道、socket 和重定向普通文件作为临时列表；`/dev/null` 和终端 stdin 使用持久化列表。
`add`、`done` 忽略 stdin；`done` 永不完成临时选中项。

输入须为 UTF-8，最多 1 MiB、过滤后最多 1,000 项，每项同样最多 2,000 字符。
读取等待 EOF；编码、控制字符或大小无效返回 1，不显示部分选择。
仅实现简单逐行过滤：

- trim 后忽略空行及 ATX 标题（1–6 个 `#` 后接空白或行尾）。
- 去除 `-`、`*`、`+`，或十进制数字加 `.`/`)` 后接空白的列表前缀。
- 忽略 `[x]`/`[X]` 已勾选项，去除 `[ ]`；`]` 后须为空白或行尾。
- 其余文本保留；不是完整 Markdown parser，不处理 setext 标题或代码围栏、不推断任务。

从剩余行均匀随机选一条；重复行分别计为候选。空列表成功。
临时选择**完全不打开状态**：持久化状态不可用或损坏时也能使用，不会改变持久化选中项。
不执行任务文本、不联网。

## CLI 与测试

成功为 0，I/O/状态错误为 1，CLI 用法错误为 2。支持 `--help`、`--version`、
`--verison`，帮助与消息按首个非空 `LC_ALL` → `LC_MESSAGES` → `LANG` 选择中英文。
用户任务文本不翻译。目标平台为 Linux/macOS/WSL Unix，本轮执行验证来自 Linux。

隐藏钩子：`ONE_SEED=<u64>` 固定同版本、同候选顺序的选择；无效或缺失值使用熵。
不影响任务 ID 或已有选中项，不显示于帮助。

测试：`cargo test -p one`，覆盖稳定选择、管道隔离、记录校验、权限/符号链接、
锁争用、并发写入、locale 和非 UTF-8 路径。
