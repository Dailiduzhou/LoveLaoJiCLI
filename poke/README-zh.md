# poke

```sh
poke add "小明"
poke
poke remove "小明"
```

一个全局本地姓名/昵称列表。只输出“如果愿意，向这位朋友问个好: 小明”之类建议。
不发送消息、不读取系统通讯录、不调用 API。

## 最小行为

- add/remove 去除首尾空白。姓名须为非空单行，最多 200 个 Unicode 字符、无控制字符；
  最多 1,000 人。
- 按大小写及 Unicode 原文精确去重：`Alex` 和 `alex` 不同；不做 Unicode 归一化，
  不要求真实姓名。
- 重复添加或移除不存在姓名友好成功，不重写列表。空名单提示 `poke add <name>`，返回 0。
- 直接运行均匀随机选一项，可连续选中同一人。无持久化选中项、避免重复算法、
  联系历史、时间戳、提醒负债、评分或定时后台服务。
- 不读取 stdin、不导入管道、不查询联系人、不联网、不发消息。

## 状态与隐私

明文姓名保存在 `${XDG_STATE_HOME:-$HOME/.local/state}/lovelaojicli/poke/names.json`。
空/相对 XDG 回退绝对 HOME；列表在所有工作目录间共享。
共享存储提供目录 0700、文件 0600、原子 JSON 替换、带密钥校验和
`poke/names.lock` 非阻塞 OS 锁。

读/改/写位于同一锁内。争用、损坏、未知 schema、符号链接或不安全权限返回 1，
不偷偷重置名单。并发调用遇到争用可能需要重试。
随机选择不写历史、不修改列表；首次运行仍可能创建状态目录、身份与锁文件。
卸载保留名单；移除不等于从磁盘/备份安全擦除。不要输入秘密：姓名未加密，
命令行文字还可能进入 shell 历史或进程列表。

## CLI 与测试

支持 `--help`、`--version`、`--verison` 及以上三种 MVP 形式。
消息按首个非空 `LC_ALL` → `LC_MESSAGES` → `LANG` 选择中英文，姓名原文不翻译。
成功为 0，状态/I/O 错误为 1，无效 CLI 输入为 2。Ctrl+C 默认行为，不更改终端模式。

隐藏钩子：`POKE_SEED=<u64>` 固定同版本、同名单顺序的均匀随机选择；无效值回退随机熵。
不是 CLI 参数，不显示于帮助。

`cargo test -p poke` 覆盖 CLI/locale、精确去重、容量、可复现重复选择、全局范围、
私有权限、损坏/符号链接/锁状态、并发和非 UTF-8 状态路径。目标为 Linux/macOS/WSL，
本轮只在 Linux 验证；磁盘故障完整注入和 macOS/WSL 仍待补。
