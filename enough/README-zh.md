# enough

提醒“最近已经通过”，不是构建缓存。[English](README.md)

```sh
enough [--again] [--] <command> [args...]
enough cargo test
enough --again cargo test
```

业务选项必须放在子命令前，之后的参数按原始边界传递。不隐式调用 shell，
需要时显式写 `sh -c`。缺少命令返回 2，支持中英文帮助、版本和 `--verison`。

## 状态机

只有真实成功、执行前后代码快照一致且输入可比较，才建立成功基线。
下次调用的规范化 cwd、原始 argv 边界和代码快照都相同时，且仍在**真实完成后 5 分钟内**，
可以不启动子命令，stdout 为空、stderr 提示、返回 0。
提示依次是“已经通过了。”“没有观察到变化。”“够了。”“不必了。”，之后保持最后一句。
英文为 `It already passed.` / `Nothing changed.` / `enough.` / `no.`。

跳过只增加提示次数，不刷新完成时间，不新增成功执行记录。时钟倒退或未来记录使资格失效。
`--again` 始终真实执行，失败、启动失败、中断、快照变化均使旧成功资格失效。

快照包含 HEAD/索引、跟踪及非忽略未跟踪文件的实际字节、路径/类型/可执行位/
符号链接文本及 cwd，而非 mtime 或 diff stat；两次扫描检查竞争，执行前后仍需一致。
限额为 20,000 条目、累计读取 256 MiB、5 秒。
子模块、冲突、过滤器、超预算、状态/锁/指纹故障、非 Git、无 Git 或输入不可比较时
**执行真实命令**。管道/重定向 stdin 或无法确认前台终端不会触发跳过。
并发重叠执行不建立可靠的新基线；执行租约与短时状态写锁分开。

stdin/stdout/stderr 原样继承，工具提示只写 stderr。真实退出码透传，信号 128+N，
找不到程序 127、不可执行 126；记录失败不改变真实结果。
Ctrl+C 通过共享前台进程组送达，不创建 detached 子进程、不自行处理信号，
不承诺约束故意 daemonize 的后代。

## 使用边界与隐私

不能证明忽略文件、环境、服务、数据库、外部文件、时间、随机性或 stdin 内容不变。
不宜默认包装部署/写数据等副作用命令、外部状态敏感测试及需要输出的管道；
请直接运行或 `--again`。不会根据程序名推断安全性。

状态根目录 `${XDG_STATE_HOME:-$HOME/.local/state}/lovelaojicli/`，目录 0700、
文件 0600，版本化带密钥校验 JSON、原子写入与 OS 锁。
只保存 argv 边界明确的本地带密钥摘要及程序 basename，不落盘 argv/shell 正文、
环境或输出。真实记录在调用时清理超过 30 天的可识别非活动记录；成功资格仅 5 分钟。
不自动修复损坏记录，密钥丢失使旧记录失效，卸载保留状态。
路径和程序名本身也可能敏感，摘要不是加密。文件系统限制见根 README。

测试：`cargo test -p enough`（Git、Python 3；真实前台 PTY 覆盖跳过、并发、stdin、Ctrl+C）。
没有绕过安全判断的测试参数。
