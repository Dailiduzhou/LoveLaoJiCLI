# patience

[English](README.md)

给真实命令配一条假进度条的包装器：运行命令、演完整场戏，把退出码原样奉还。

```sh
patience make -j4
patience sleep 5
patience patience sleep 3   # 多一层耐心，多一条进度条
```

顶层 [`README.md`](../README.md) 记录使用方式；本文件写给好奇的人：每个小巧思背后的决策与实现。

## 子命令，而不是选项

patience 没有任何用户可见的 flag（除 `--help` / `--version`）。要等待的东西天然是一整行命令，用 `trailing_var_arg` 原样吃下更符合直觉——`patience make -j4` 里的 `-j4` 属于 make，不属于耐心。零 flag 就是零心智负担。

子命令本身以 `--` 开头时（如 `patience -- git status`），用一个 `--` 分隔即可。

## 套娃特判

`patience patience sleep 3` 同时显示两条进度条。实现上是**前缀特判，不是递归进程**：

- 前缀的 `patience` 记号逐个剥掉，每个对应一条进度条；第一个非 `patience` 记号起才是真实子命令（`./patience`、`Patience` 都不算）。
- 不真的 spawn 套娃进程：内层的 stderr 会被外层捕获进管道，非 TTY 下根本不渲染，"同时显示多条"就无从谈起。所以多条条全部由最外层渲染，共享同一个真实子进程的生命周期。
- 每条条独立演出：各自的曲线、卡点、安慰语。随机种子用 splitmix64 与条序号混合派生，`PATIENCE_SEED` 固定时逐条逐帧可复现。
- 彩虹相位按条序号均匀错开（`index × 30 / 条数`），叠在一起不像复印件。
- 仅在原有有界区域仍可信时用光标上移 `\x1b[{N-1}A` 刷新，单条用回车。
- 命令行深度不封顶，但条数达到或超过终端高度时禁用动画；真实命令仍只运行一次。

## 随机演出

每次运行从七种速度曲线随机抽一种：匀速、先慢后快、先快后慢、S 型、阶梯式（像写得不好的安装器）、指数逼近（看着很忙，永远差一点）、平方根（起步很快，尾巴拖得更长）。

脚本由"爬升 + 小卡"交替构成：1~4 个短卡（0.5~2s），卡点严格递增且相距至少 3%；最后停在 97~99.9% 的**永恒卡**——只要子命令还活着，进度条就永不再动。

子命令成功退出才冲刺：每帧约 3.3%，半秒内填满 100%；失败则停在原地，绝不填满——结果不撒谎。最低演出时长 0.5~1.5s，即使子命令秒退，也让你等出诚意。

## 卡点安慰语

卡住时随机抽一句安慰语：洗牌成牌堆，按序抽取，绝不连续重复，抽空重洗。

## 彩虹跑马灯

调色板是 13 个锚点组成的无缝循环渐变：条宽恰好一个完整彩虹周期。

界线默认斜 45°：每格用半块字符 `▀` 上下双色调，按 `color(x, y) = palette(x + k·y + phase)` 取色——2:1 的字符格子下 `k = cot(45°) = 1`，分界线恰好呈 45° 斜边。相位随时间推进（每 tick 一格，整条彩虹约 1.5s 滑过一遍），所以静态截图里也能看见斜的界线在滑动。

按终端能力自动降级：真彩 → 256 色 → 16 色 → 无色原样，尊重 `NO_COLOR` 与 `TERM=dumb`。Windows conhost 需要时以一次 `SetConsoleMode` 打开 VT 转义支持。

## 行为契约

- 退出码原样透传（信号终止则 128+N）；子命令不存在 → 127；没给命令 → 2。
- 子进程输出逐流捕获（每流上限 1MiB），演出结束后回放，截断有注记。
- 非 TTY 不渲染任何动画，只回放输出与结果行——管道和 CI 干干净净。

## 有界布局与降级

使用 rustix 读取 **stderr 所属终端**的尺寸，不运行外部工具、不查询光标。
预留一列及一行，保留完整百分比；优先省略安慰语，再把正常 30 格条宽缩短（最低 8 格）。
仅为工具自带的有限文案计算中文/模糊标点的保守显示宽度，不扩展通用 Unicode 宽度库。
条宽只影响采样与显示，不改变随机计划、卡点或真实子命令结果。

TERM 缺失/能力未知、尺寸未知/过小、条数过多或 stderr 非 TTY 时只回放输出和结果，
没有动画转义。一旦观察到尺寸变化，本次调用永久停止动画，不按旧坐标向上擦写，
放大也不重启；不承诺消除终端自行重排的旧内容。非空 `NO_COLOR` 只禁颜色，
不禁止其他仍安全的光标控制。绝不为布局裁剪真实子命令输出。

`cargo test -p patience` 包含 `tests/layout_pty.py`：20/24/40/80/120 列、
中英文、叠条、高度/TERM 降级、缩放、颜色层级，以及未开启 FAST 的原始中文 40 列 `sleep 8` 复现。

## 测试钩子

全部走环境变量，不进 `--help`。

| 变量 | 作用 |
| --- | --- |
| `PATIENCE_SEED=<u64>` | 固定所有随机，含每条条的派生种子 |
| `PATIENCE_FAST=1` | 所有时间缩至 1% |
| `PATIENCE_COLOR=truecolor\|256\|16\|none` | 强制颜色层级，覆盖自动检测 |
| `PATIENCE_ANGLE=<0..90>` | 色带界线角度，默认 45° |

种子的可复现性以版本为界，不跨版本：往 `Curve::ALL` 里加变体会改变种子到曲线列表的映射，同一个 `PATIENCE_SEED` 之后会抽到另一场演出。
