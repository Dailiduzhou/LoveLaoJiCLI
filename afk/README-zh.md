# afk

不带惩罚的安静休息。

```sh
afk 5m
afk 15m
afk 30s
afk 1h
```

时长为 ASCII 十进制正整数加小写 `s`、`m` 或 `h`，不超过 24 小时（86,400 秒）。
允许前导零；符号、小数、空格、缺少单位、零或溢出返回 2。
时长必填；没有 `--until`、循环或其他业务选项。

用 `Instant` 单调时钟计时，不使用墙上时钟。安静等待，结束向 stdout 打印“休息结束。”。
I/O 错误为 1，正常结束为 0。

## 明确的终端降级

**本版所有终端都采用路线图允许的纯文本降级**，不只是非 TTY 或 `TERM=dumb`。
ASCII 生长场景和 `the grass noticed.` 按键提示暂缓。没有新增终端依赖：
raw mode 在错误、挂起/恢复和信号退出下的可靠恢复需要另行实现生命周期并验证。

本版没有 raw mode、键盘读取、备用屏幕、光标修改或信号处理器，不更改终端属性。
正常完成、输出失败、Ctrl+C、SIGTERM、SIGHUP 均无需恢复终端。
Ctrl+C 使用正常前台终端信号取消，不打印完成行（调用 shell 通常呈现退出码 130）。
不消费按键、不扣分，输入不会重置或延长计时。终端正常行规程仍适用：
输入可能回显、留给 shell、挂起进程或暂停终端输出；这不是输入过滤器或强制休息。

不保存状态、不联网、不调用桌面服务；没有锁屏、后台常驻、通知、streak 或生产力评分。
目标平台为 Linux/macOS/WSL Unix；本轮在 Linux 验证，包含完成、参数/输出错误及
取消/信号路径下终端属性不变的 PTY 测试。macOS/WSL 待验；因为不用 raw mode，
不宣称完成 raw mode 恢复验证。

支持 `--help`、`--version`、`--verison`。按首个非空 `LC_ALL` → `LC_MESSAGES` → `LANG`
选择语言（zh-CN/zh_CN/zh 为中文，其余英文）。

隐藏测试钩子：只有 `AFK_FAST=1` 将正常校验后的时长缩至 1%；其他值忽略，不显示于帮助。

测试：`cargo test -p afk`（PTY 测试需要 Python 3）。
