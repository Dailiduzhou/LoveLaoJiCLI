# proof

```sh
proof
```

显示今天可用的本地证据，不评分、不估算努力。除帮助/版本外没有参数，
不读取 stdin、shell 历史、桌面活动或其他仓库。不写状态、不代执行任务、不联网；
仅调用有预算的本地 Git 探测。

## Git 统计口径

- 只看本 checkout 采集开始时固定的当前 HEAD 及可达本地祖先，不扫描其他分支、
  reflog 或仓库。未提交文件变化不计入。
- 作者须同时精确匹配当前有效 Git 配置 `user.name` **和** `user.email`，
  比较原始字段，不用正则、大小写折叠或 mailmap。缺失/空配置使来源未知，不冒充零提交。
- 按 **committer 时间戳**，不是 author 时间；落入调用时本地当天且不晚于采集当前秒。
  不用 `--since` 提前剪枝：时间较旧的子提交也可能有今天的父提交。
- 提交数包括本人合并提交和空提交。增删行仅累加非合并 `--numstat` 补丁，含根提交；
  是累计变更量，不是相对午夜的净变化，更不是工作量。
- 路径按原始字节去重。关闭 rename 检测，重命名前后算不同路径。
  二进制只计路径，不编造行数。NUL 分隔解析支持 tab/换行/非 UTF-8 文件名，不打印路径。
  相关探测禁用外部 diff、textconv、签名展示、hooks 和按需联网取对象。
- 浅历史、缺对象、Git/HEAD 不可用、采集期间 HEAD 改变、无效输出或超预算时，
  整个 Git 来源标未知，不输出部分数字。未产生首提交/裸仓库目前 Git 证据未知。

Git 每个输出流上限 32 MiB，每次进程限 5 秒。最多 20,000 条历史、
1,000 条今天匹配作者提交、20,000 个去重变更路径、32 MiB 累计 numstat；
在探测间检查 10 秒采集预算，正在运行的探测仍有自己的 5 秒上限。
大历史即使今天只有少量提交，也可能保守显示未知。

## 本地日期

可选 `cli-common/local-time` 只启用 jiff 的 std/系统时区/zoneinfo 支持。
遵从系统时区或 `TZ`，不内置时区数据库、不联网。起止为日历日边界，
DST 日期不假定总为 24 小时。时区缺失/无效显示未知，不偷偷回退 UTC。
排除未来时间的提交与执行记录。没有公开或隐藏时钟开关；DST/边界测试直接向内部
时间函数传入时间戳。

## 显式执行记录

仅已有 enough/stuck 运行记录，按当前 worktree 隔离，非 Git 按 cwd。
没有记录只代表没有**记录的**执行，不代表没工作。按完成时间落入今天统计，
所以昨晚开始、今天完成的命令可以计入。

只统计完整真实 exited/signal 结果；退出 0 称“成功执行”，**不一定是测试**。
启动/等待失败、未完成、流转发不完整、未来结果、enough 跳过、stuck 拦截不计入。
重复基线不是执行记录。即使重复优化禁用，多次真实执行仍分别计入。

读取不创建目录/密钥/锁文件，不清理历史、不修复状态、不改其他工具的选中项。
使用已有 identity/workspace 共享锁；不安全、损坏、未知记录或锁争用使来源未知。
最多扫描 10,000 条 / 32 MiB，在记录间检查 5 秒预算。缺少状态即空，已有状态却无
身份密钥则不可用。包装器原有保留期限和 fail-open 行为意味着它不是全部 shell
命令的完整审计日志。

两个来源均无可用证据时，输出“暂无工作记录。”（英文为 `no recorded work.`），
仍保留未知来源说明和“缺少记录不代表没有工作”的提示。不排名、不记录 streak、
不跨仓库发现、不猜终端活跃时间。

## CLI 与测试

支持 `--help`、`--version`、`--verison`；语言按首个非空
`LC_ALL` → `LC_MESSAGES` → `LANG` 选择。成功或证据未知为 0，输出错误为 1，
用法错误为 2。默认信号处理；不要求 stdin/TTY。目标 Linux/macOS/WSL，本轮只在 Linux 验证。

```sh
cargo test -p proof
cargo test -p cli-common --features local-time
cargo build --locked --workspace --release
python3 tests/report_records_pty.py target/release
```

覆盖 DST、作者/日期/可达性、合并/根提交/二进制/重命名统计、记录校验、锁、
只读行为及真实包装器执行/跳过/拦截。macOS/WSL、全部历史时区异常和完整资源故障注入
仍待补验，不宣称已全部验证。
